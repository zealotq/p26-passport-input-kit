常用操作

sudo 密码：按住空格 + q..p 数字层，输入你自己的口令
方向键：按住空格 + a s d f（↑ ↓ ← →）
Esc：按住空格 + z　标点：按住空格 + b n m（，。？）
剪贴板：按住空格 + c / v / x（Ctrl+C / Ctrl+V / Ctrl+X）
F5 刷新：按住空格 + g　软键盘开关：按住空格 + l
中英切换：按住空格 + 退格（WowType zh ↔ en）
触摸板：直接滑动 = 方向键，随时可用，无需按空格；灵敏度 600/350。
不按空格时所有键原样输出，正常打字不受影响。
